Paso 1: ¿Hardware o Software?

HW

Hardware Lo Tangible

Es toda la parte física y material de la computadora. Todo aquello que puedes tocar con las manos, conectar, desconectar o armar.

Ejemplos Clave:
Procesador Teclado Monitor Memoria RAM
SW

Software Lo Intangible

Es el conjunto de programas, aplicaciones e instrucciones digitales que le dicen al hardware exactamente qué hacer. No se puede tocar.

Ejemplos Clave:
Windows / macOS Navegadores Videojuegos Word / Excel

Paso 2: Unidades de Medida y Almacenamiento

Unidad Mínima

BIT (Binary Digit)

0 (OFF)

Es la unidad de información más pequeña en informática. Solo puede tomar dos valores: 0 o 1. Funciona exactamente como un interruptor de luz encendido o apagado.

Bloque Básico

BYTE (8 Bits)

Es un conjunto formado por 8 Bits en grupo. Representa el espacio exacto que ocupa una sola letra, número o símbolo (por ejemplo, la letra 'A').

1 Byte =
0 1 0 0 0 0 0 1

Escala de Almacenamiento (Analogías)

Kilobyte (KB) 1,024 Bytes

Un texto muy corto o una carta breve digital.

Ej: Un párrafo de texto.
Megabyte (MB) 1,024 KB

Archivos multimedia estándar o fotos comprimidas.

Ej: Una canción MP3 o foto.
Gigabyte (GB) 1,024 MB

Archivos pesados de alta calidad o software.

Ej: Una película HD.
Terabyte (TB) 1,024 GB

Enorme capacidad de almacenamiento masivo.

Ej: Una biblioteca entera.

Paso 3: Componentes de la Computadora

Haz clic en cada uno para explorar
Cerebro

CPU (Procesador)

Unidad Central de Procesamiento

Es el verdadero "cerebro" de la computadora. Se encarga de procesar todas las instrucciones de las aplicaciones, ejecutar programas y realizar operaciones matemáticas.

¿Para qué sirve? Calcular y Ejecutar
Memoria Rápida

Memoria RAM

Memoria de Acceso Aleatorio

Es la memoria de trabajo ultrarrápida pero temporal. Mantiene abiertos los programas y pestañas activos. Al apagar la PC, esta información se borra.

¿Para qué sirve? Multitarea Temporal
Almacenamiento

Disco Duro / SSD

Almacenamiento Permanente

Guarda tus archivos, fotos, juegos, canciones y el Sistema Operativo a largo plazo. Nada se borra aunque apagues la computadora.

¿Para qué sirve? Guardar Archivos
Conector Principal

Tarjeta Madre (Motherboard)

Placa Base de Circuitos

Es la gran placa sobre la cual se conectan y comunican entre sí todos los demás componentes (CPU, RAM, Discos, Gráfica).

¿Para qué sirve? Unir Componentes
Energía

Fuente de Poder (PSU)

Power Supply Unit

Recibe la corriente eléctrica de la pared, la transforma a voltajes seguros y la distribuye con precisión a cada parte de la computadora.

¿Para qué sirve? Alimentar Energía
Vídeo y Gráficos

Tarjeta Gráfica (GPU)

Unidad de Procesamiento Gráfico

Especializada en procesar exclusivamente imágenes, vídeos, modelos 3D y juegos para enviarlos proyectados a la pantalla.

¿Para qué sirve? Renderizar Gráficos

Periféricos: Entrada y Salida

Dispositivos de Entrada

Introducen información o datos desde el usuario hacia la computadora.

Teclado Mouse / Ratón Micrófono Cámara Web

Dispositivos de Salida

Muestran o entregan los resultados procesados hacia el usuario.

Monitor / Pantalla Altavoces / Bocinas Impresora
