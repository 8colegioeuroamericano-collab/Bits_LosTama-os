Hardware vs Software

Las dos columnas fundamentales sobre las que opera cualquier sistema informático.

Hardware

Lo Tangible (Físico)

Es todo lo que **puedes tocar físicamente**. Corresponde a los circuitos, chips, componentes electrónicos, cables, gabinetes y periféricos.

Ejemplos clave:
Procesador (CPU) Memoria RAM Disco SSD Teclado y Monitor

Software

Lo Intangible (Lógico)

Es el conjunto de **instrucciones, programas y datos** informáticos que le dicen al Hardware exactamente qué hacer y cómo operar.

Ejemplos clave:
Sistema Operativo (Windows/Linux) Navegador Web Videojuegos

La Mazorca de Maíz y los Bytes

Para entender las medidas digitales de forma sencilla, imagina una Mazorca de Maíz:

  • 1
    El Bit (1 Grano): Es un solo grano de maíz individual (un 0 o un 1). Por sí solo no forma casi nada.
  • 2
    El Byte (Una Letra / Mazorca de 8 granos): Al juntar 8 bits (granos), formamos 1 Byte. Un Byte es el equivalente exacto al espacio necesario para almacenar **1 sola letra** (por ejemplo, la letra 'A').
  • 3
    KiloByte, MegaByte y Más: Un KiloByte (KB) son aprox. 1,000 Bytes (un paquete entero de mazorcas), un MegaByte (MB) son 1,000 KB, y así sucesivamente.
Demostración: 1 Byte = 8 Bits (1 Carácter)

Bit (b)

La unidad mínima. Representa un estado binario: Encendido (1) o Apagado (0).

8 Bits

Byte (B)

Equivale al espacio ocupado por un carácter/letra individual.

~1,000 Bytes

KiloByte (KB)

1,000 Bytes (o 1,024 B). Es suficiente para almacenar un párrafo pequeño de texto plano.

~1,000 KB

MegaByte (MB)

1,000 KB. Típico para una canción MP3 (~3 a 5 MB) o una foto de alta resolución.

Dato Importante de Clase: Megabits (Mb) vs MegaBytes (MB)

La 'b' minúscula significa bits (usado en velocidad de Internet, ej. 100 Mbps). La 'B' mayúscula significa Bytes (usado para peso de archivos). Recuerda: ¡1 MegaByte equivale a 8 MegaBits!
